၁၄။ ဧတဒဂ္ဂဝဂ္ဂေါ

၁။ ပဌမဝဂ္ဂေါ

၁၈၈။ ‘‘ဧတဒဂ္ဂံ ¶ ¶ ၊ ဘိက္ခဝေ၊ မမ သာဝကာနံ ဘိက္ခူနံ ရတ္တညူနံ ယဒိဒံ အညာသိကောဏ္ဍညော’’ [အညာတကောဏ္ဍညောတိ (က။)၊ အညာကောဏ္ဍညော (သီ။ သျာ။ ကံ။ ပီ။)]။

၁၈၉။ … မဟာပညာနံ ယဒိဒံ သာရိပုတ္တော။

၁၉၀။ … ဣဒ္ဓိမန္တာနံ ယဒိဒံ မဟာမောဂ္ဂလ္လာနော။

၁၉၁။ … ဓုတဝါဒါနံ [ဓုတင်္ဂဓရာနံ (ကတ္ထစိ)] ယဒိဒံ မဟာကဿပေါ။

၁၉၂။ … ဒိဗ္ဗစက္ခုကာနံ ယဒိဒံ အနုရုဒ္ဓါ။

၁၉၃။ … ဥစ္စာကုလိကာနံ ယဒိဒံ ဘဒ္ဒိယော ကာဠိဂေါဓာယပုတ္တော။

၁၉၄။ … မဉ္ဇုဿရာနံ ယဒိဒံ လကုဏ္ဍက [လကုဏ္ဋက (သျာ။ ကံ။)] ဘဒ္ဒိယော။

၁၉၅။ … သီဟနာဒိကာနံ ¶ ယဒိဒံ ပိဏ္ဍောလဘာရဒွါဇော။

၁၉၆။ … ဓမ္မကထိကာနံ ယဒိဒံ ပုဏ္ဏော မန္တာဏိပုတ္တော။

၁၉၇။ … သံခိတ္တေန ဘာသိတဿ ဝိတ္ထာရေန အတ္ထံ ဝိဘဇန္တာနံ ယဒိဒံ မဟာကစ္စာနောတိ။

ဝဂ္ဂေါ ပဌမော။

၂။ ဒုတိယဝဂ္ဂေါ

၁၉၈။ ‘‘ဧတဒဂ္ဂံ ¶ ¶ ၊ ဘိက္ခဝေ၊ မမ သာဝကာနံ ဘိက္ခူနံ မနောမယံ ကာယံ အဘိနိမ္မိနန္တာနံ ယဒိဒံ စူဠပန္ထကော’’ [စုလ္လပန္ထကော (သီ။ သျာ။ ကံ။ ပီ။)]။

၁၉၉။ … စေတောဝိဝဋ္ဋကုသလာနံ ယဒိဒံ စူဠပန္ထကော။

၂၀၀။ … သညာဝိဝဋ္ဋကုသလာနံ ယဒိဒံ မဟာပန္ထကော။

၂၀၁။ … အရဏဝိဟာရီနံ ယဒိဒံ သုဘူတိ။

၂၀၂။ … ဒက္ခိဏေယျာနံ ယဒိဒံ သုဘူတိ။

၂၀၃။ … အာရညကာနံ ယဒိဒံ ရေဝတော ခဒိရဝနိယော။

၂၀၄။ … ဈာယီနံ ယဒိဒံ ကင်္ခါရေဝတော။

၂၀၅။ … အာရဒ္ဓဝီရိယာနံ ယဒိဒံ သောဏော ကောဠိဝိသော။

၂၀၆။ … ကလျာဏဝါက္ကရဏာနံ ယဒိဒံ သောဏော ကုဋိကဏ္ဏော။

၂၀၇။ … လာဘီနံ ယဒိဒံ သီဝလိ။

၂၀၈။ … သဒ္ဓါဓိမုတ္တာနံ ယဒိဒံ ဝက္ကလီတိ။

ဝဂ္ဂေါ ဒုတိယော။

၃။ တတိယဝဂ္ဂေါ

၂၀၉။ ‘‘ဧတဒဂ္ဂံ ¶ ၊ ဘိက္ခဝေ၊ မမ သာဝကာနံ ဘိက္ခူနံ သိက္ခာကာမာနံ ယဒိဒံ ¶ ရာဟုလော’’။

၂၁၀။ … သဒ္ဓါပဗ္ဗဇိတာနံ ¶ ယဒိဒံ ရဋ္ဌပါလော။

၂၁၁။ … ပဌမံ သလာကံ ဂဏှန္တာနံ ယဒိဒံ ကုဏ္ဍဓာနော။

၂၁၂။ … ပဋိဘာနဝန္တာနံ ယဒိဒံ ဝင်္ဂီသော။

၂၁၃။ … သမန္တပါသာဒိကာနံ ယဒိဒံ ဥပသေနော ဝင်္ဂန္တပုတ္တော။

၂၁၄။ … သေနာသနပညာပကာနံ ယဒိဒံ ဒဗ္ဗော မလ္လပုတ္တော။

၂၁၅။ … ဒေဝတာနံ ပိယမနာပါနံ ယဒိဒံ ပိလိန္ဒဝစ္ဆော။

၂၁၆။ … ခိပ္ပာဘိညာနံ ယဒိဒံ ဗာဟိယော ဒါရုစီရိယော။

၂၁၇။ … စိတ္တကထိကာနံ ယဒိဒံ ကုမာရကဿပေါ။

၂၁၈။ … ပဋိသမ္ဘိဒါပတ္တာနံ ယဒိဒံ မဟာကောဋ္ဌိတောတိ [မဟာကောဋ္ဌိကောတိ (အညေသု သုတ္တေသု မရမ္မပေါတ္ထကေ)]။

ဝဂ္ဂေါ တတိယော။

၄။ စတုတ္ထဝဂ္ဂေါ

၂၁၉။ ‘‘ဧတဒဂ္ဂံ၊ ဘိက္ခဝေ၊ မမ သာဝကာနံ ဘိက္ခူနံ ဗဟုဿုတာနံ ယဒိဒံ အာနန္ဒော’’။

၂၂၀။ … သတိမန္တာနံ ¶ ယဒိဒံ အာနန္ဒော။

၂၂၁။ … ဂတိမန္တာနံ ¶ ယဒိဒံ အာနန္ဒော။

၂၂၂။ … ဓိတိမန္တာနံ ယဒိဒံ အာနန္ဒော။

၂၂၃။ … ဥပဋ္ဌာကာနံ ယဒိဒံ အာနန္ဒော။

၂၂၄။ … မဟာပရိသာနံ ယဒိဒံ ဥရုဝေလကဿပေါ။

၂၂၅။ … ကုလပ္ပသာဒကာနံ ယဒိဒံ ကာဠုဒါယီ။

၂၂၆။ … အပ္ပာဗာဓာနံ ယဒိဒံ ဗာကုလော [ဗက္ကုလော (သီ။ သျာ။ ကံ။ ပီ။)]။

၂၂၇။ … ပုဗ္ဗေနိဝါသံ အနုဿရန္တာနံ ယဒိဒံ သောဘိတော။

၂၂၈။ … ဝိနယဓရာနံ ယဒိဒံ ဥပါလိ။

၂၂၉။ … ဘိက္ခုနောဝါဒကာနံ ¶ ယဒိဒံ နန္ဒကော။

၂၃၀။ … ဣန္ဒြိယေသု ဂုတ္တဒွါရာနံ ယဒိဒံ နန္ဒော။

၂၃၁။ … ဘိက္ခုဩဝါဒကာနံ ယဒိဒံ မဟာကပ္ပိနော။

၂၃၂။ … တေဇောဓာတုကုသလာနံ ယဒိဒံ သာဂတော။

၂၃၃။ … ပဋိဘာနေယျကာနံ ယဒိဒံ ရာဓော။

၂၃၄။ … လူခစီဝရဓရာနံ ¶ ယဒိဒံ မောဃရာဇာတိ။

ဝဂ္ဂေါ စတုတ္ထော။

၅။ ပဉ္စမဝဂ္ဂေါ

၂၃၅။ ‘‘ဧတဒဂ္ဂံ ¶ ၊ ဘိက္ခဝေ၊ မမ သာဝိကာနံ ဘိက္ခုနီနံ ရတ္တညူနံ ယဒိဒံ မဟာပဇာပတိဂေါတမီ’’။

၂၃၆။ … မဟာပညာနံ ယဒိဒံ ခေမာ။

၂၃၇။ … ဣဒ္ဓိမန္တီနံ ယဒိဒံ ဥပ္ပလဝဏ္ဏာ။

၂၃၈။ … ဝိနယဓရာနံ ယဒိဒံ ပဋာစာရာ။

၂၃၉။ … ဓမ္မကထိကာနံ ယဒိဒံ ဓမ္မဒိန္နာ။

၂၄၀။ … ဈာယီနံ ယဒိဒံ နန္ဒာ။

၂၄၁။ … အာရဒ္ဓဝီရိယာနံ ယဒိဒံ သောဏာ။

၂၄၂။ … ဒိဗ္ဗစက္ခုကာနံ ယဒိဒံ ဗကုလာ [သကုလာ (သီ။ သျာ။ ကံ။ ပီ။)]။

၂၄၃။ … ခိပ္ပာဘိညာနံ ယဒိဒံ ဘဒ္ဒါ ကုဏ္ဍလကေသာ။

၂၄၄။ … ပုဗ္ဗေနိဝါသံ အနုဿရန္တီနံ ယဒိဒံ ဘဒ္ဒါ ကာပိလာနီ။

၂၄၅။ … မဟာဘိညပ္ပတ္တာနံ ယဒိဒံ ဘဒ္ဒကစ္စာနာ။

၂၄၆။ … လူခစီဝရဓရာနံ ယဒိဒံ ကိသာဂေါတမီ။

၂၄၇။ … သဒ္ဓါဓိမုတ္တာနံ ¶ ယဒိဒံ သိင်္ဂါလကမာတာတိ [သိဂါလမာတာတိ (သီ။ သျာ။ ကံ။ ပီ။)]။

ဝဂ္ဂေါ ပဉ္စမော။

၆။ ဆဋ္ဌဝဂ္ဂေါ

၂၄၈။ ‘‘ဧတဒဂ္ဂံ ¶ ၊ ဘိက္ခဝေ၊ မမ သာဝကာနံ ဥပါသကာနံ ပဌမံ သရဏံ ဂစ္ဆန္တာနံ ယဒိဒံ ¶ တပုဿဘလ္လိကာ [တပဿုဘလ္လိကာ (သီ။ ပီ။)] ဝါဏိဇာ’’။

၂၄၉။ … ဒါယကာနံ ယဒိဒံ သုဒတ္တော ဂဟပတိ အနာထပိဏ္ဍိကော။

၂၅၀။ … ဓမ္မကထိကာနံ ယဒိဒံ စိတ္တော ဂဟပတိ မစ္ဆိကာသဏ္ဍိကော။

၂၅၁။ … စတူဟိ သင်္ဂဟဝတ္ထူဟိ ပရိသံ သင်္ဂဏှန္တာနံ ယဒိဒံ ဟတ္ထကော အာဠဝကော။

၂၅၂။ … ပဏီတဒါယကာနံ ယဒိဒံ မဟာနာမော သက္ကော။

၂၅၃။ … မနာပဒါယကာနံ ယဒိဒံ ဥဂ္ဂေါ ဂဟပတိ ဝေသာလိကော။

၂၅၄။ … သင်္ဃုပဋ္ဌာကာနံ ယဒိဒံ ဟတ္ထိဂါမကော ဥဂ္ဂတော ဂဟပတိ။

၂၅၅။ … အဝေစ္စပ္ပသန္နာနံ ယဒိဒံ သူရမ္ဗဋ္ဌော [သူရော အမ္ဗဋ္ဌော (သီ။ သျာ။ ကံ။ ပီ။) သုရေဗန္ဓော (က။)]။

၂၅၆။ … ပုဂ္ဂလပ္ပသန္နာနံ ယဒိဒံ ဇီဝကော ကောမာရဘစ္စော။

၂၅၇။ … ဝိဿာသကာနံ ¶ ယဒိဒံ နကုလပိတာ ဂဟပတီတိ။

ဝဂ္ဂေါ ဆဋ္ဌော။

၇။ သတ္တမဝဂ္ဂေါ

၂၅၈။ ‘‘ဧတဒဂ္ဂံ ¶ ၊ ဘိက္ခဝေ၊ မမ သာဝိကာနံ ဥပါသိကာနံ ပဌမံ သရဏံ ဂစ္ဆန္တီနံ ယဒိဒံ သုဇာတာ သေနိယဓီတာ’’ [သေနာနီ ဓီတာ (သီ။ သျာ။ ကံ။ ပီ။)]။

၂၅၉။ … ဒါယိကာနံ ယဒိဒံ ဝိသာခါ မိဂါရမာတာ။

၂၆၀။ … ဗဟုဿုတာနံ ယဒိဒံ ခုဇ္ဇုတ္တရာ။

၂၆၁။ … မေတ္တာဝိဟာရီနံ ယဒိဒံ သာမာဝတီ။

၂၆၂။ … ဈာယီနံ ယဒိဒံ ဥတ္တရာနန္ဒမာတာ။

၂၆၃။ … ပဏီတဒါယိကာနံ ယဒိဒံ သုပ္ပဝါသာ ကောလိယဓီတာ။

၂၆၄။ … ဂိလာနုပဋ္ဌာကီနံ ¶ ယဒိဒံ သုပ္ပိယာ ဥပါသိကာ။

၂၆၅။ … အဝေစ္စပ္ပသန္နာနံ ယဒိဒံ ကာတိယာနီ။

၂၆၆။ … ဝိဿာသိကာနံ ယဒိဒံ နကုလမာတာ ဂဟပတာနီ။

၂၆၇။ … အနုဿဝပ္ပသန္နာနံ ယဒိဒံ ကာဠီ ဥပါသိကာ ကုလဃရိကာ [ကုလဃရိကာ (က။)] တိ။

ဝဂ္ဂေါ သတ္တမော။
